# Study guide format (Build mode)

## Before writing

1. Read the whole source. List its chapters and sections; keep the source's terms and definitions.
2. For each section, find: core idea, causal chains, the one diagram that matters, a calculation type, typical exam questions, and links to other sections.
3. Decide the medium: an interactive page (answers hidden behind a click, self-rating per question, progress saved) is best for retrieval. A document works if answers sit after the questions, not next to them.

## Unit template

```markdown
## [Number] [Section title]

### Warm-up (try first)
1. …
2. …

### Kernidee
…

### Wirkungskette
1. Ursache … → 2. … → 3. Wirkung …

### Diagramm
[visual] – How to read it: …

### Zahlenbeispiel
Given … → Step 1 … → Step 2 … → Result …
(Illustrative numbers unless taken from the source.)

### Typische Fehler
- Mistake → fix

### Verknüpfungen
- Same logic as … / Contrast with …

### Abruffragen
1. [definition] …
2. [why/how] …
3. [calculation] …
4. [diagram] …
5. [transfer case] …
(Answers hidden / in "Lösungen")
```

## Question mix per unit

- 2 definitions or distinctions (cued recall)
- 2–3 why/how questions targeting the causal chain
- 1 calculation
- 1 diagram question (what shifts, where is the optimum)
- 1 transfer case from everyday business
- optional: 1 multiple choice with a plausible distractor (hybrid tests work best)

## Gemischte Runde

12–20 questions drawn from all units in shuffled order. Prefer pairs that look alike but need different reasoning. Label each with its unit only in the answer.
