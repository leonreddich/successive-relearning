# Relearning plan

## Inputs

Exam date, hours per day, number of units, weak ledger (if a diagnosis was run).

## Schedule rules

- **Session 1 (initial learning):** each item to 3 correct recalls within the session, spread out (move to other items between attempts).
- **Relearning sessions:** each item to 1 correct recall; missed items are restudied briefly and re-tested later in the same session until correct.
- **Number of sessions:** aim for 3–5 relearning sessions before the exam. Later sessions are fast, because most items come back on the first try.
- **Gaps:** expanding gaps work well in practice: day 0 → day 1 → day 3 → day 7 → … Keep the last session 1–2 days before the exam, not the same night.
- **Sleep:** place session 1 in the afternoon or evening and session 2 the next morning or day.
- **Mixed rounds:** from the second session on, start with a mixed round across all units before unit-wise practice.

## Short horizons

| Days until exam | Plan |
|---|---|
| 1 | Today: learn to criterion in blocks with short breaks; evening mixed round. Morning: one quick relearning round, weak items only plus a small mixed sample. |
| 3–4 | Day 0 learn; day 1 relearn; day 2 mixed + weak; day before exam short relearn. |
| 7–14 | Day 0, 1, 3, 7 and day before exam; weak items get an extra session. |
| > 14 | Expanding gaps (1, 3, 7, 14 days), last session 1–2 days before the exam. |

## In one day (when everything has to be learned today)

1. Blocks of 45–60 min per unit, 5–10 min break.
2. Each block: warm-up questions → read the unit → close it → answer the unit's questions from memory → check → re-test misses at the end of the block.
3. After every 2–3 units: a mixed round over all units so far (this is spacing within the day).
4. Evening: one full mixed round; write misses into the Fehler-Log.
5. Next day: relearn the Fehler-Log first, then a mixed round.
